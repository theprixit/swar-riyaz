# Swar Riyaz

Two single-file practice tools for Hindustani classical music, hosted on GitHub Pages.

- **swar.html** — Swar Pehchan, an ear trainer. Synthesised tanpura drone on your Sa, random swar, you sing it then name it. Per-swar accuracy is kept in the browser.
- **lehra.html** — Lehra Saath, a lehra (nagma) player: simple one-note-per-matra lehras in Teentaal, Jhaptaal, Ektaal, Rupak, Keherwa and Dadra, with a visual taal cycle, sam/tali clicks, tap tempo and a tanpura drone.
- **tabla.html** — Tabla Sur, a live microphone tuner. Pick your Sa (or read it off the harmonium), strike the drum, and a cents needle tells you which way to tap the gatta.

No build step, no dependencies beyond Google Fonts. Open the files directly or serve them over https (the tuner needs https or localhost for microphone access).
